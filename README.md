# Flow State Tracker

10 hours of screen time does not always mean 10 hours of productivity. Flow State Tracker breaks down app and website use, idle time, typing speed, activity, and window switches so you can better understand how you spend your time.

## Features

- Tracks the foreground application and browser domain.
- Separates active use, idle time, and media playback.
- Shows typing speed, activity, and focus-switch trends.
- Summarizes usage by hour, day, week, and month.
- Stays available from the Windows system tray when its window is closed.
- Stores tracking data locally.

## Run from source

Flow State Tracker currently targets Windows. Install the Flutter SDK and Visual Studio's **Desktop development with C++** workload, then run:

```powershell
flutter pub get
flutter run -d windows
```

To build a release:

```powershell
flutter build windows --release
```
